# Contributing to UI-FleetFlow

Thank you for your interest in contributing to **UI-FleetFlow**, the open-source fleet management and logistics routing platform for the University of Ibadan campus community.

## Ways to Contribute

1. **Reporting Bugs**: Open an issue detailing the unexpected behavior, steps to reproduce, and environment details.
2. **Feature Suggestions**: Propose new logistics optimization algorithms, campus telematics telemetry features, or UI improvements.
3. **Pull Requests**:
   - Fork the repository and create a feature branch (`git checkout -b feature/new-algorithm`).
   - Write clean, documented Python code adhering to PEP 8 standards.
   - Ensure all automated unit and integration tests pass:
     ```bash
     pytest -v
     ```
   - Commit your changes and open a Pull Request.

## Development Setup

```bash
git clone <repository-url>
cd <repository-directory>
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python run.py
```


## Code of Conduct

Please maintain a collaborative, respectful, and inclusive environment for all students, researchers, and open-source contributors.
